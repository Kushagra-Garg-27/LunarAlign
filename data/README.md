# Data Directory

Place sample Chandrayaan-2 images here for development and testing.

## Supported Formats
- OHRC, TMC-2 panchromatic images (GeoTIFF, PDS)
- IIRS hyperspectral cubes (IMG, HDF5)

## Sources
- ISRO PRADAN: https://pradan.issdc.gov.in
- Chandrayaan Data Explorer / MapBrowse

See `PROJECT_SPEC.md` §18 for full data source documentation.
